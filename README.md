# 🎮 PARALLEL – The Two Worlds
## 🚀 Play the Game

🎮 **[PLAY PARALLEL – LIVE DEMO]( https://jyotisihagjaat.github.io/Parallel-The-Two-Worlds/)**

**A browser-based puzzle platformer where two worlds exist side by side.**

PARALLEL is a 2D browser game built using HTML, CSS, and JavaScript. Players explore different levels, switch between the Light and Shadow worlds, collect crystals, avoid obstacles, and reach the portal to complete each level.

## ✨ Features

- 🌗 Two interactive worlds: Light and Shadow
- 🎯 Multiple challenging levels
- 💎 Crystal collection and scoring system
- 🌀 World-switching mechanics
- ⌨️ Keyboard controls
- 📱 Responsive mobile-friendly controls
- ⏸️ Pause and restart options
- 🏆 Progress and score saved locally

## 🕹️ How to Play

- Move left and right to navigate.
- Jump to cross platforms and obstacles.
- Press **E** to switch between worlds.
- Collect crystals.
- Reach the portal to complete the level.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- HTML Canvas

## 🚀 Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
